# Heart Disease Prediction

## Project Overview
This project predicts the likelihood of heart disease using Machine Learning algorithms.

## Dataset
Heart Disease Dataset from Kaggle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Project Steps
1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Model Evaluation

## Models Used
- Logistic Regression
- Random Forest Classifier
- K-Nearest Neighbors (KNN)

## Results

| Model | Accuracy |
|---------|---------|
| Random Forest | 85.25% |
| Logistic Regression | 78.69% |
| KNN | 63.93% |

## Best Model
Random Forest Classifier

## Conclusion
Random Forest achieved the highest performance and was selected as the final model for heart disease prediction.
